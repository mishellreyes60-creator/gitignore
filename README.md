# # # Sistema de Control de Asistencias Universitarias

## Descripción

Sistema desarrollado para llevar el control de asistencia de los estudiantes de una universidad. El proyecto busca facilitar el registro, consulta y seguimiento de la asistencia a clases, evitando procesos manuales y permitiendo tener la información organizada.

## Objetivo

Crear un sistema que permita registrar y administrar la asistencia de los estudiantes de manera rápida, sencilla y organizada, facilitando a docentes y administradores el seguimiento de la asistencia de cada alumno..

## Funcionalidades

Registrar estudiantes.
Registrar docentes.
Registrar materias y cursos.
Registrar la asistencia de los estudiantes.
Marcar estudiantes como presente, ausente o justificado.
Consultar el historial de asistencias.
Buscar asistencia por estudiante, materia o fecha.
Calcular el porcentaje de asistencia de cada estudiante.
Identificar estudiantes con bajo porcentaje de asistencia.
Editar o corregir registros de asistencia.
Generar reportes de asistencia.

## Instalación o ejecución

1.Clonar o descargar el repositorio.
2.Abrir el proyecto en el editor de código.
3.Instalar los requisitos o dependencias necesarias.
4.Configurar la base de datos, si corresponde.
5.Ejecutar el archivo principal del sistema.
6.Iniciar sesión como administrador o docente.
7.Registrar estudiantes, materias y cursos.
8.Comenzar a registrar las asistencias.
